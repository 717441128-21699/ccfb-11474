# 合理用药知识审查平台

把医院药剂科的药品说明书(docx/pdf)自动切成标准章节、抽取结构化用药知识,
并提供浏览器审核台与审方系统导出。覆盖**说明书库、抽取明细、知识图谱、
审核台、冲突检查**五个功能模块。

## 能力对照(需求 → 实现)

| 需求 | 实现 |
| --- | --- |
| 1. 按标准章节切开,标题五花八门也要对上 | `app/parser/headings.py` 同义词表 + 编号剥离,4 套标题风格(国标【】/中文编号/阿拉伯数字/无编号近义),20 个标准章节 |
| 2. 相互作用抽药物对/类型/严重程度 | `app/extract/interaction.py`,药物对最长匹配+`本品`回填,17 类作用类型,4 级严重程度 |
| 3. 剂量按成人/儿童/肝肾不全分开,用量频次拆字段 | `app/extract/dosage.py`,5 类人群、min/max/单位/频次标准码/给药途径,检验指标数值自动排除 |
| 4. 药名统一通用名,商品名别名挂接 | `app/normalize/`,92 个通用名词典 + 精确/模糊匹配 + 盐基短名 canonical 映射 |
| 5. 每条知识带原文出处,点击高亮原句 | 全部条目存 `source_start/end` 字符偏移,前端抽屉 `<mark>` 高亮并滚动定位(4361 条偏移校验 0 失败) |
| 6. 两份说明书矛盾说法单独列表 | `app/extract/conflicts.py`,禁忌对立/等级跨两级/方向相反三类,`/api/conflicts` 独立页 |
| 7. 审核通过的知识导出给审方系统 | `app/extract/exporter.py`,带版本号+SHA256 校验和+出处的 JSON |

## 目录结构

```
app/
  config.py              路径/阈值/标准章节定义
  db/                    SQLAlchemy 模型与会话
  parser/                docx/pdf 读取、标题归一化、章节切分
  normalize/             药名归一化、canonical 短名映射
  extract/               相互作用/剂量/禁忌抽取、冲突检测、导出、流水线编排
  eval/                  gold 基准评估器
  api/                   FastAPI 路由
  main.py                应用入口(API + 前端托管)
scripts/                 样本生成、入库、评估、服务、诊断脚本
web/                     原生 JS 审核台(无构建依赖)
tests/                   29 个 pytest 单元/端到端测试
data/
  drug_dictionary.json   药名词典(92 通用名,商品名/别名挂接)
  raw/                   500 份样本说明书(docx 60% / pdf 40%)
  gold/                  人工标注(模拟)+ 标注规范
  db/ export/ processed/ 数据库、导出、评估与诊断产物
```

## 快速开始

```powershell
# 1. 安装依赖
py -m pip install -r requirements.txt

# 2. 生成 500 份样本(含 gold 标注)
py -I scripts/run_generate.py --count 500

# 3. 药名词典入库 + 批量解析抽取
py -I scripts/load_dictionary.py
py -I scripts/run_ingest.py

# 4. 跑评估(P/R)
py -I scripts/run_eval.py

# 5. 启动浏览器审核台
py -I scripts/run_server.py --port 8000
# 打开 http://127.0.0.1:8000
```

> `-I` 为隔离模式,避免当前目录被植入的同名模块(如 json.py)影响导入。

## 评估结果(500 份样本)

| 指标 | 精确率 P | 召回率 R | F1 |
| --- | --- | --- | --- |
| 相互作用·药物对 | **1.0000** | **0.9918** | 0.9959 |
| 相互作用·药物对+严重程度 | **1.0000** | **0.9836** | 0.9917 |
| 相互作用·全字段(含作用类型) | **1.0000** | **0.9819** | 0.9909 |
| 剂量字段 | **1.0000** | **1.0000** | 1.0000 |
| 章节切分 | **1.0000** | **1.0000** | 1.0000 |

相互作用准确率与召回率均超过九成的验收线。剩余 FN 为与词典名零字符重叠的
生造扰动(如「庆霉大素」),系统选择宁缺毋滥,精确率保持 100%。

## 设计说明

- **规则文法而非黑盒模型**:抽取全部基于可解释的关键词文法与正则,每条结论
  可回溯到具体规则与原句,符合药师审查的可解释要求。
- **偏移同源**:章节切分重建带确定偏移的全文,抽取器与前端高亮共用同一偏移体系。
- **gold 与系统解耦**:gold 标注由生成参数直接结构化产出,不经过被测抽取器,
  避免"自己考自己"。
- **真实落地替换点**:接入真实说明书时,替换 `data/raw` 与药名词典即可;
  标题同义词表、抽取关键词表可在不改代码的情况下持续扩充。
